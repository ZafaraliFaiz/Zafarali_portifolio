## ✨ Key Portfolio Features

* ⚡ **Interactive Architecture Visualizer:** Deep-dive into interactive diagrams demonstrating state management, token refresh interceptors, offline write queues, and CI/CD pipelines.
* 💻 **Built-in CLI Terminal Modal (`Ctrl + K`):** Interactive hacker terminal supporting commands like `help`, `skills`, `projects`, `exp`, `research`, `cat resume`, and `clear`.

* 🌌 **Dynamic Interactive Constellation Canvas:** High-FPS physics particle background rendered via HTML5 Canvas.

## 🚀 Getting Started Locally

### Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher recommended)
* [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ZafaraliFaiz/zafarali_portifolio.git
   cd zafarali_portifolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` to view it in your browser.

4. **Build production bundle:**
   ```bash
   npm run build
   ```

5. **Type check:**
   ```bash
   npm run lint
   ```
